THE LONG WAY AROUND

The journey, not the straight line

Life rarely moves in a perfectly straight line. Sometimes you reach the point by taking the long way around. Here's the path, curves included — still being written.

CHAPTER ONE

Building with my hands

Before any of this had a name, there was a job site, a set of tools, and a willingness to figure things out by doing them wrong first. That's where the instinct to build actually started.

Lesson: craftsmanship is just repeated honesty about your own mistakes.
CHAPTER TWO

Starting to build with code

Curiosity about software, AI, and everything adjacent to it turned into late nights teaching myself to build. The same instincts from the job site — measure twice, ship once — carried straight over.

Lesson: the tools change. The discipline doesn't.
CHAPTER THREE

Too many ideas

Once the door to building digital things opened, it didn't stay open a crack. AI companions, estimating software, security experiments, a game, a podcast — more ideas than any one person can chase at once.

Lesson: ideas deserve to be tested, not worshiped.
CHAPTER FOUR

Learning to ship

Running Iron Legion Contracting LLC while experimenting in software meant learning the difference between an idea and a finished thing — and getting more comfortable putting unfinished work in front of people.

Lesson: build before you brag.
CHAPTER FIVE

Building something that matters

Solen, The Long Way Around, and the rest of what's in the workshop are the current attempt to turn the habit of building into something that genuinely helps someone else move forward.

Lesson: success has more value when it lets someone else move forward too.
NEXT CHAPTER

HOW THIS SITE WAS BUILT

This website is also a case study

An honest look at the real architecture behind what you're looking at right now — no invented metrics, just what's actually running.

Rendering

Three.js (ES modules, no bundler) with custom GLSL shaders — a simplex-noise morph shader for the hero's physical/digital duality, a fresnel-glow shader for Solen, and dedicated shaders for AlphaQuote's blueprint grid and Syntrax's scan line. One restrained UnrealBloom post-processing pass runs on the hero on capable devices; the Constellation gets its identity from per-project shaders instead of a second bloom pass, deliberately, to keep two concurrent WebGL scenes affordable.

Adaptive performance

A real HIGH / MEDIUM / LOW / FALLBACK quality-tier system — not scattered conditionals — picks device tier from hardware signals up front, then watches actual frame timing and downgrades bloom, resolution, and geometry detail automatically if the site is struggling.

Scroll & motion

GSAP ScrollTrigger scrubs a camera along a Catmull-Rom spline behind the Journey timeline. Every animated element respects prefers-reduced-motion.

Ask About Brandon

A local keyword/alias/fuzzy-matching engine — not an LLM — reading from the same projects.js / profile.js data the rest of the site renders from, so it can't say anything the site doesn't already say.

Structure

Native ES modules, no framework, no build step: index.html + organized /css and /js (scenes, shaders, data, UI) — a static site any host can serve.

Ship pipeline

GitHub (Brandon-The-Builder141/brandon-brumbaugh-site) deployed to Railway as a static Node service.
